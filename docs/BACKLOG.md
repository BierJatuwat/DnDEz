(การตัดสินใจที่ล็อกแล้วและประวัติ sprint อยู่ใน [`PROJECT-CONTEXT.md`](./PROJECT-CONTEXT.md))

## ยังไม่เคยทดสอบกับของจริง

ทุกเทสต์ใช้ `FakeAnthropicClient` — ฟีเจอร์ AI ทั้งหมดยังไม่เคยรันกับ Claude จริงเลย ต้องใช้ API key ของตัวเอง
(ตั้งได้ในหน้า DM console)

- **นำเข้าเนื้อเรื่องจาก PDF/ภาพ** (`StoryImportEndpoints`) — ลองไฟล์จริงสักไฟล์ ดูว่าแยกฉากออกมาสมเหตุสมผลไหม
  และ "สรุปฉาก" ไม่มีความลับหลุดเข้าไป (ช่องนี้ถูกส่งให้ AI ที่เล่าเรื่องให้ผู้เล่นฟัง)
- **ผู้ช่วย DM** (`/assistant`) — ลองคำสั่งหลายขั้นจริง เช่น "เอาก็อบลิน 3 ตัวลงแล้วเปิดไฟต์"
- timeout ของการอ่านเอกสารตั้งไว้ 5 นาที (`AnthropicClient.ExtractionTimeout`) ยังไม่เคยวัดว่า PDF ยาวจริงใช้เวลาเท่าไหร่

## รอตัดสินใจ

- **สิทธิ์ตาราง `story_beats` ที่ชั้น DB** — policy เป็น `app_is_member()` ผู้เล่นอ่านแถวได้รวม `secrets`/`dm_notes`
  และฉากที่ยังไม่ผ่านตรวจ ตอนนี้ไม่รั่วเพราะ API ของฉากเป็น DM-only และเทิร์นผู้เล่นเลือกอ่านแค่ title/objective/summary
  · เปลี่ยนเป็น `dm_only` ตรง ๆ ไม่ได้ เพราะเทิร์นผู้เล่นต้องอ่านฉากที่ active ในนามผู้เล่นจริง — ทางออกคือแยกช่องลับ
  ไปตาราง/view ต่างหาก
- **co-DM ใน `assistant_runs`** — policy `dm_only` เช็คแค่ `app_is_dm()` ไม่ได้ผูก `dm_user_id` วันนี้ปลอดภัยเพราะทุก
  query ฝั่งแอปกรอง `DmUserId` ซ้ำ (`AssistantEndpoints` GET, `AssistantRunner.DecideAsync`) แต่ถ้าวันหน้ามี DM หลายคน
  ต่อแคมเปญ ชั้น RLS อย่างเดียวจะไม่กันบทสนทนาลับข้ามกัน · **เจ้าของโปรเจกต์สั่งให้เก็บไว้ก่อน ห้ามแก้จนกว่าจะสั่ง**
  (2026-09-24) — ถ้าจะทำฟีเจอร์ co-DM ต้องยกเรื่องนี้ขึ้นมาคุยก่อน
- **embedding provider** — ต้องเลือกก่อนทำ `raw_chunks` (ค้นเนื้อหาในเอกสารที่นำเข้า) Anthropic ไม่มี embeddings API
  ดูเหตุผลที่แนะนำรันเองใน `PROJECT-CONTEXT.md` §4

## ออกแบบไว้แล้ว ยังไม่ได้ทำ

- ดึง **มอนสเตอร์ / NPC / แผนที่** จากเอกสารที่นำเข้า (ตอนนี้ได้แค่ story beat) — ตาราง `monster_stat_blocks`/
  `npc_profiles`/`map_assets` มีคอลัมน์ `source_document_id` รออยู่แล้ว · ต้องผ่านหน้า DM review เหมือนฉาก
  (ตัวเลข AC/HP ผิดแล้วเกมพัง)
- ให้ผู้ช่วย DM **สั่งโจมตีแทนมอนสเตอร์/NPC** — เลื่อนไว้เพราะ logic ใน `CombatEndpoints` ซับซ้อน
- **streaming** คำตอบของผู้ช่วย DM (ตอนนี้รอทั้งก้อนแล้วขึ้น "กำลังทำงาน…")

## หนี้ทางเทคนิคที่รู้แล้ว

- **quota race ตอนอัปโหลดแผนที่** (`SceneEndpoints` map-assets) — อ่าน quota ตอนต้นแล้วเขียนค่าที่อ่านไว้ตอนท้าย
  อัปโหลดพร้อมกันสองคำขอทะลุ quota ได้ · การนำเข้าเนื้อเรื่องแก้แล้วด้วย `ExecuteUpdateAsync` แบบมีเงื่อนไข
  (ดู `StoryImportEndpoints`) ใช้วิธีเดียวกันได้ · ความรุนแรงต่ำกว่าเพราะไม่มีช่วงรอ AI
- **ไม่มีโค้ดลบไฟล์ใน MinIO เลย** (grep `DeleteObject` ทั้ง `src/` ไม่เจอ ณ 2026-11-05) — ตอนนี้ยังไม่มี endpoint ลบ
  แคมเปญ/แผนที่/เอกสาร จึงยังไม่เป็นปัญหา แต่ใครทำฟีเจอร์ลบต้องลบ object (`map-assets/…`, `source-documents/…`)
  และคืน `storage_quotas.used_bytes` ด้วย
